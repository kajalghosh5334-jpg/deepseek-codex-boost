# 微信/企业微信自动添加好友脚本

用于创建和维护一个通过 pyautogui 模拟键鼠操作、在微信或企业微信中自动批量添加好友的 Python 脚本。

## 适用场景
- 有一批手机号+姓名需要批量添加微信好友
- 需要自动化重复的添加操作
- 需要坐标校准、暂停控制、断点续传等交互体验

## 脚本结构

典型的项目文件：
- `run.py` — 主脚本（自动添加）
- `get_pos.py` — 坐标校准工具
- `set_progress.py` — 断点管理工具
- `contacts.xlsx` — 数据源（表头需含手机号列和姓名列）
- `.progress` — 自动生成的断点文件（记录当前进度索引）

## 微信版 vs 企业微信版

**微信版**（本项目）流程：搜索框 → 输入号码 → 回车搜索 → 查找手机号 → 添加到通讯录 → 验证消息 → 备注 → 确定 → 清空 → 下一轮

**企业微信版**（参考 `/Users/yipengfei/Desktop/AutoAdd/`）流程：添加按钮 → 输入号码 → 搜索 → 添加 → 清空验证信息 → 粘贴话术 → 发送 → 清空

## 关键经验

### 1. 坐标校准
- 不要硬编码坐标，提供独立的校准工具 `get_pos.py`
- 校准工具用 **tkinter 弹窗** 提示每一步（零依赖）
- 弹窗放**右上角**，避免挡住操作区域
- 用户按 **Enter** 采集坐标，按 **Esc** 跳过
- 采集后用**正则替换**自动写入 `run.py`

### 2. 输入方式
- 微信/企业微信搜索框不是标准 input，`pyautogui.typewrite()` 不可靠
- **必须用粘贴**：`pyperclip.copy()` + `Cmd+V`
- 搜索号码后必须按 **Enter** 触发搜索，微信才会出现「查找手机号」选项
- 每轮结束后用 `Cmd+A` + `Backspace` 清空搜索框

### 3. 清空输入框
- 不要用点击叉号（✕），不可靠
- **统一用 `Cmd+A` 全选 + `Backspace` 退格**，适用于搜索框、验证消息框、备注框
- 对于空输入框（首次使用），全选+退格无害，可以放心执行

### 4. 失败弹窗处理
- 添加失败时微信/企业微信会弹提示
- 发送后自动按一次 **Enter** 关闭弹窗，不影响正常流程

### 5. 暂停/恢复控制
- **不要用 pynput**（与 pyautogui 冲突，按键监听不可靠）
- **不要用子线程 tkinter 控制面板**（Python 3.14 会崩溃）
- 使用终端的 `sys.stdin` + `select` 非阻塞轮询
- 在每个 `sleep` 间隙检查键盘输入
- 按键逻辑：**P** 暂停/继续，**Q** 退出
- 暂停/恢复时发 macOS 系统通知

### 6. 断点续传
- 用 `.progress` 文件记录已完成的索引
- 每处理完一条立即写入，Ctrl+C/Q 退出都不丢进度
- 启动时自动从断点继续
- 提供 `set_progress.py` 工具：
  - `python3 set_progress.py 姓名` — 从指定人开始
  - `python3 set_progress.py 数字` — 从第 N 条开始
  - `python3 set_progress.py` — 查看当前进度
  - `python3 set_progress.py --reset` — 重置从头开始

### 7. Excel 数据读取
- **兼容多种表头**（模糊匹配）：
  - 手机号列：`手机号`、`电话`、`手机`、`手机号码`、`电话号码`、`联系电话`、`联系方式`、`电话号`、`号码`
  - 姓名列：`姓名`、`名字`、`名称`、`昵称`、`称呼`、`备注名`、`联系人`
- 同时读取姓名和手机号，用于生成备注：`姓名+手机号`（如 `黄雨萱1298979797`）

### 8. 按钮位置偏移处理
- 微信用户资料页中，「添加到通讯录」按钮可能因朋友圈内容被挤到下方
- 解决方案：从校准位置向下连续点击多下，间隔 20px（约 0.6cm），覆盖偏移范围
- 只在校准位置以下扫描，不向上

### 9. 备注填写
- 微信添加页面有独立的「备注」输入框，需要单独采集坐标
- 备注内容 = 姓名 + 手机号
- 填写前先 `Cmd+A` + `Backspace` 清空，再粘贴
- 备注框连点两次确保焦点获取

### 10. Python 版本兼容
- Python 3.14 的 `pynput` 可能崩溃（SIGILL）
- Python 3.14 的 tkinter 子线程弹窗可能崩溃
- 优先使用纯标准库方案（`tkinter` 仅主线程用，`select` + `sys.stdin`）

### 11. 动作间隔
- 每个操作间隔：1-2 秒随机
- 界面加载等待：3-5 秒
- 联系人之间的防封号延迟：15-35 秒随机

### 12. 防封号
- 每条之间有 15-35 秒随机延迟
- 遇到异常立即停止，防止乱点
